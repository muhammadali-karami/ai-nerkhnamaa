# افزونهٔ نرخ‌نما

این افزونه برای Chrome و Firefox با Manifest V3 ساخته شده است و با کلیک روی آیکن، نرخ طلای ۱۸ عیار، دلار آمریکا و تتر را در پنجرهٔ افزونه نشان می‌دهد.

## Chrome

1. به `chrome://extensions` بروید.
2. حالت **Developer mode** را فعال کنید.
3. **Load unpacked** را بزنید و همین پوشه را انتخاب کنید.

## Firefox

1. به `about:debugging#/runtime/this-firefox` بروید.
2. **Load Temporary Add-on** را انتخاب کنید.
3. فایل `manifest.json` همین پوشه را انتخاب کنید.

برای نصب دائمی Firefox، افزونه باید پیش از انتشار امضا شود.

دو فایل آمادهٔ نصب هم در همین پوشه قرار دارند: `rate-nama-chrome.zip` و `rate-nama-firefox.zip`.
